# 선표

직접 선을 그어 표를 만들고 텍스트를 넣은 후, 굿노트에 쓸 PNG 또는 PDF로 저장하는 정적 웹앱입니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **GitHub Actions**를 선택합니다.
3. `main` 브랜치에 올릴 때마다 배포됩니다.

배포된 주소에서 모든 편집과 저장이 브라우저 안에서 이뤄집니다.

## PDF를 캔버스로 불러오기

상단의 **PDF 불러오기**에서 30MB 이하의 PDF 파일을 선택하면 첫 페이지가 잠긴 배경으로 표시되고, 캔버스 크기도 그 페이지 비율에 맞춰 바뀝니다. 다른 페이지를 쓰려면 **설정 열기 → 페이지 → PDF 페이지**에서 번호를 바꾸거나 이전·다음 버튼을 누르세요. 페이지를 바꿔도 지금까지 그린 선과 텍스트는 같은 좌표로 유지되므로, 새 페이지의 크기가 다르면 일부 내용이 보이지 않을 수 있습니다. **되돌리기**로 이전 페이지로 돌아갈 수 있습니다.

기본 저장은 이전처럼 그린 내용만 잘라서 내보냅니다. **설정 열기 → 내보내기 → PDF 배경까지 저장**을 켜면 배경을 포함한 페이지 전체를 PNG 또는 PDF로 저장합니다. 배경이 포함되면 투명 PNG 설정은 적용되지 않습니다. 글 때문에 표가 페이지 아래로 늘어나면 PDF 바깥쪽은 빈 배경으로 확장됩니다.

PDF 파일과 그림 데이터는 서버에 전송하지 않고 이 브라우저의 기기 저장소에 보관합니다. 사이트 데이터가 삭제되거나 브라우저가 저장을 허용하지 않으면 PDF를 다시 선택해야 합니다. PDF 읽기에는 프로젝트에 포함된 [PDF.js](https://mozilla.github.io/pdf.js/)를 사용합니다.

## 칸 안에 글 쓰기

선 도구로 네 변이 닫힌 사각형 칸을 만든 뒤 **텍스트** 도구로 칸 안을 누르세요. 입력창에서 글을 직접 쓰고 왼쪽·가운데·오른쪽 정렬을 고를 수 있습니다. 글이 늘어나면 해당 행과 그 아래 선이 아래로 이동합니다. **완료**를 누르면 저장되며, 다시 칸을 누르면 수정할 수 있습니다.

## 휴대폰에서 사용하기

캔버스는 처음에 화면 너비에 맞춰 표시됩니다. `＋`로 확대하고 **화면 이동** 도구로 드래그해 원하는 위치로 이동하세요. `맞춤`을 누르면 전체 너비로 돌아옵니다. 색상, 선 굵기, 페이지 크기와 내보내기 옵션은 **설정 열기**에서 조절할 수 있습니다. 텍스트 칸을 누르면 읽기 쉬운 크기로 자동 확대됩니다.

애플펜슬처럼 브라우저가 펜으로 인식하는 도구로 캔버스를 누르면 **펜슬로만 그리기**가 자동으로 켜집니다. 이때 펜슬은 선택한 그리기 도구를 사용하고, 손가락 한 개로 캔버스를 이동하거나 칸을 눌러 텍스트를 입력할 수 있습니다. 손가락 두 개를 벌리거나 오므리면 확대·축소됩니다. 손가락으로 다시 그리려면 **설정 열기 → 펜슬로만 그리기**를 끄세요. 브라우저는 펜슬의 연결 여부 자체를 알려주지 않으므로 첫 펜 입력을 기준으로 전환됩니다.
