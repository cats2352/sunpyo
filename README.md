# 선표

직접 선을 그어 표를 만들고 텍스트를 넣은 후, 굿노트에 쓸 PNG 또는 PDF로 저장하는 정적 웹앱입니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 **GitHub Actions**를 선택합니다.
3. `main` 브랜치에 올릴 때마다 배포됩니다.

배포된 주소에서 모든 편집과 저장이 브라우저 안에서 이뤄집니다.

## 칸 안에 글 쓰기

선 도구로 네 변이 닫힌 사각형 칸을 만든 뒤 **텍스트** 도구로 칸 안을 누르세요. 입력창에서 글을 직접 쓰고 왼쪽·가운데·오른쪽 정렬을 고를 수 있습니다. 글이 늘어나면 해당 행과 그 아래 선이 아래로 이동합니다. **완료**를 누르면 저장되며, 다시 칸을 누르면 수정할 수 있습니다.

## 휴대폰에서 사용하기

캔버스는 처음에 화면 너비에 맞춰 표시됩니다. `＋`로 확대하고 **화면 이동** 도구로 드래그해 원하는 위치로 이동하세요. `맞춤`을 누르면 전체 너비로 돌아옵니다. 색상, 선 굵기, 페이지 크기와 내보내기 옵션은 **설정 열기**에서 조절할 수 있습니다. 텍스트 칸을 누르면 읽기 쉬운 크기로 자동 확대됩니다.
